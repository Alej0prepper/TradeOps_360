This directory records significant architectural decisions as TradeOps 360 evolves. A decision record should explain the context, the chosen approach, its consequences, and why alternatives were not selected.

Future files may use a sequential format such as `001-reuse-res-partner.md`. Do not create decision records before the corresponding implementation or discussion makes them necessary.

The purpose is to preserve design intent without filling application code with comments about routine Python or Odoo syntax.
